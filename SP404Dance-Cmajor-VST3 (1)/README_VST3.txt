SP-404 Dance — Online Cloud VST3 Build (Zero Local Installs)
============================================================

1. Create a new repository on github.com (any name, e.g. sp404-dance-vst3).
2. Click "uploading an existing file" in the browser.
3. Unzip this archive and drag ALL files (including the .github folder!) into GitHub, then click "Commit changes".
4. Open the "Actions" tab in your GitHub repository.
5. Wait ~3 minutes for "Build SP-404 Dance VST3" to finish.
6. Click the completed run and download "SP404Dance-Windows-VST3" (or macOS).
7. Put the .vst3 folder into C:\Program Files\Common Files\VST3\ and rescan plugins in FL Studio!
